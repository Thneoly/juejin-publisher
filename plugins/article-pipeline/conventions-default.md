# 体例纪律（默认版）

> 这份文件是 article-pipeline 的评审标尺。按需改成你自己的规范——评审官会逐条照此对照。
> 改这份文件 = 改整条生产线的质量标准。

## 来源与事实

1. 来源标注只用四档档名：【官方】【平台样本】【第三方转引】【从业者判断】+ 时点；限定语放档名后逗号处（如【第三方转引，XX 媒体，2026-09】）
2. 媒体/Newsletter/转述渠道一律【第三方转引】，不得标【官方】——官方只留给一手来源
3. 每个市场数字必须带来源档+时点；材料里查无出处的 →【从业者判断】或删除，绝不裸引
4. 引用规范文档/母文档的判据逐字保真（条目、标点都不动）；转述时不加引号不称「原文」

## 发布安全（平台机审）

5. 正文禁止出现 URL 与域名字符串（掘金机审按「推广类」驳回的重灾区）——一律写成「在 XX 平台搜 YY 可复核」这类纯文字指引
6. 招聘/薪资类内容控制密度：具体数字引用要挂媒体转引来源，不堆砌

## 排版与文风

7. 加粗 ≤30 字；移动端短段（一段不超过 4 行）
8. 构造案例必须标注「构造典型案例」，不可识别到真人真公司
9. 文风：观点鲜明、判断直接，每节有一句可被独立引用的判断句；禁止正确的废话
10. 开头 3 行内立钩子；结尾 CTA 给读者一个可参与的行动（提问/挑战/晒单）

## frontmatter（多平台发布）

11. title_zhihu / title_juejin 分开写（两平台语域不同：知乎判断句、掘金干货句）
12. description 50~100 字（硬性）；tags 按目标平台映射且数量符合平台上限
